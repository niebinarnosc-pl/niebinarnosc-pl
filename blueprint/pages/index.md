# Pages Blueprint (Astro)

This module documents the page structure of the website. It outlines each page, its purpose, the content it displays, and how it is implemented in the Astro project.

## Module Documentation

*   [`abstract.md`](./abstract.md): Provides a framework-agnostic overview of the site's pages and their content requirements.
*   [`implementation.md`](./implementation.md): Describes the specific implementation of each page as an Astro file, including data fetching from Sanity and routing.
*   [`issues.md`](./issues.md): A log of significant issues or challenges encountered during page development.
