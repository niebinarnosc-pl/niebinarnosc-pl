# Components Blueprint (Astro)

This module defines the component architecture for the new Astro-based version of the project. It outlines the philosophy, structure, and implementation details for creating a modular, reusable, and maintainable component library.

This new architecture is designed to improve upon the structure of the original Gatsby project, particularly by refactoring monolithic components like `ContentItem` into smaller, more focused units.

## Module Documentation

*   [`abstract.md`](./abstract.md): Provides a framework-agnostic description of the component philosophy and high-level structure. It details the conceptual breakdown of components and addresses the refactoring strategy for `ContentItem`.
*   [`implementation.md`](./implementation.md): Describes the specific technical implementation of the component architecture using Astro and Alpine.js. It covers directory structure, component patterns (e.g., using slots), and state management.
*   [`issues.md`](./issues.md): A log of significant issues or challenges encountered during the design or implementation of the new component system.
