# Old Components Blueprint (Gatsby/React)

This module documents the original React components from the `niebinarnosc-pl-old/src/components/` directory. It serves as a reference for understanding their functionality, props, and styling, which is crucial for migrating them to the new Astro-based technology stack.

Each document provides a breakdown of a single component.

## Component Documentation

*   [`Alert.md`](./Alert.md): A component for displaying success or error messages.
*   [`ArticleContainer.md`](./ArticleContainer.md): A wrapper for long-form article content, rendering markdown.
*   [`ContactCard.md`](./ContactCard.md): A promotional card encouraging users to share their story.
*   [`ContactForm.md`](./ContactForm.md): A form for users to send messages, integrated with Netlify Forms.
*   [`ContentItem.md`](./ContentItem.md): A versatile card for displaying summaries of stories, definitions, etc.
*   [`CookieBanner.md`](./CookieBanner.md): A banner to request cookie consent from the user.
*   [`DefinitionItem.md`](./DefinitionItem.md): A component to display a single definition term and its explanation.
*   [`ExternalLink.md`](./ExternalLink.md): A simple wrapper around an `<a>` tag for external links.
*   [`Footer.md`](./Footer.md): The main site footer.
*   [`Header.md`](./Header.md): The main site header, including mobile and desktop versions.
*   [`HomeHeader.md`](./HomeHeader.md): The main header component for the homepage.
*   [`HomeNav.md`](./HomeNav.md): A navigation component with large, colorful links on the homepage.
*   [`Icons.md`](./Icons.md): A system for rendering SVG icons as React components.
*   [`Layout.md`](./Layout.md): The main layout component wrapping every page.
*   [`Lightbox.md`](./Lightbox.md): A full-screen overlay for displaying images.
*   [`Page.md`](./Page.md): A wrapper component for standard page content.
*   [`Seo.md`](./Seo.md): A component for managing all SEO-related meta tags.
*   [`TagSelector.md`](./TagSelector.md): A component for filtering content by tags.
