# ArticleContainer Component

*   **Source**: `niebinarnosc-pl-old/src/components/ArticleContainer/index.js`
*   **Styling**: `niebinarnosc-pl-old/src/components/ArticleContainer/styles.scss`

## Purpose and Functionality

The `ArticleContainer` is a wrapper component designed to display long-form article content. It takes a pre-processed HTML abstract syntax tree (AST) and renders it into HTML. This is used for pages like "Historia" (History) and "Poradnik" (Guide).

## Props

| Name      | Type     | Required | Default | Description                                 |
|-----------|----------|----------|---------|---------------------------------------------|
| `htmlAst` | `object` | Yes      | -       | The HTML AST object generated by Gatsby from a markdown file. |

## Dependencies

*   `renderAst`: A utility function that takes the `htmlAst` and renders it to React components. This allows for custom styling of specific HTML elements like headings and custom shortcodes.

## Styling

*   The container has a white background and responsive padding. On larger screens, it has rounded corners (`0.75rem`).
*   It sets a `max-width` on paragraph (`<p>`) tags to improve readability.
*   It defines specific margins for headings (`h2.article-h2`) and styles for horizontal rules (`<hr>`).
*   It includes styles for a two-column layout (`.columns`), which stacks on mobile and becomes a row on larger screens.
