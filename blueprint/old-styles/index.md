# Old Styles Blueprint (Gatsby/Sass)

This module serves as a framework-agnostic representation of the styles from the original `niebinarnosc.pl` website, which was built using Gatsby and Sass. The purpose of this documentation is to capture the complete visual and stylistic identity of the old site, so that it can be faithfully recreated using a new technology stack (Astro and Tailwind CSS).

This blueprint breaks down the styling into several key categories, each detailed in its own document.

## Style System Documentation

*   [`colors.md`](./colors.md): Defines the project's complete color palette.
*   [`typography.md`](./typography.md): Describes fonts, base text styles, heading styles, and other typographic elements.
*   [`iconography.md`](./iconography.md): Documents the SVG icon system and lists all available icons.
*   [`layout.md`](./layout.md): Outlines the responsive layout system, breakpoints, and main site structure.
*   [`effects.md`](./effects.md): Documents common visual effects like button presses, transitions, and decorative elements.
*   [`components.md`](./components.md): Provides a detailed breakdown of the styling for each UI component.
