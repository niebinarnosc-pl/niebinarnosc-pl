# Color Palette

This document defines the complete color palette used in the original project. The palette is organized into logical color groups: Gray, Purple, and Yellow.

## Grayscale

| Name      | Hex       | Sass Variable | Notes                       |
|-----------|-----------|---------------|-----------------------------|
| Black     | `#2C2C2C` | `$black`      | The primary text color.     |
| Gray 100  | `#2C2C2C` | `$gray-100`   | Alias for `$black`.         |
| Gray 80   | `#24252D` | `$gray-80`    | Dark gray shade.            |
| Gray 60   | `#454D56` | `$gray-60`    | Mid-dark gray, for subheadings. |
| Gray 40   | `#A3A3A3` | `$gray-40`    | Mid-light gray, for borders. |
| Gray 20   | `#D1D1D1` | `$gray-20`    | Light gray.                 |
| Gray 10   | `#E9E9E9` | `$gray-10`    | Very light gray.            |
| Gray 5    | `#F3F3F3` | `$gray-5`     | Off-white.                  |
| White     | `#FFFFFF` | `$white`      | Pure white.                 |
