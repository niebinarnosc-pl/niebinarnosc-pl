# CMS Blueprint

This directory outlines the Content Management System (CMS) setup and integration for the project, focusing on Sanity CMS.

This directory contains the following files detailing different aspects of the CMS:

*   [`abstract.md`](./abstract.md): Provides a high-level overview of the CMS strategy and the key content models
*   [`implementation.md`](./implementation.md): Details the technical setup of the Sanity schemas, singleton configuration, and examples of how data will be fetched with GROQ queries.
*   [`issues.md`](./issues.md): Documents any known issues related to the general CMS setup or Sanity integration.

Specific content model (schema) definitions for project features (e.g., Blog, About Page) are detailed within their respective blueprint modules.
