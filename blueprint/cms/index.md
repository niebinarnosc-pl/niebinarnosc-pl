# CMS Blueprint (Sanity)

This module documents the content management system (CMS) setup for the project, which is built using Sanity. It provides a comprehensive guide to the content model, schema definitions, and Studio configuration.

This blueprint is designed to ensure a clear understanding of how content is structured and managed, which is essential for both development and content creation.

## Module Documentation

*   [`abstract.md`](./abstract.md): Provides a framework-agnostic description of the project's content model. It details the various content types (e.g., Stories, Definitions) and their relationships.
*   [`implementation.md`](./implementation.md): Describes the specific implementation of the content model as Sanity schemas. It provides details on each schema's fields, validations, and custom components.
*   [`issues.md`](./issues.md): A log of significant issues or challenges encountered during the design or implementation of the CMS.
